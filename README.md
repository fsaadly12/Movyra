

\# Movyra



\*\*Food Delivery Management Platform\*\*



Movyra is a full-stack food delivery platform designed to connect customers, restaurants, delivery couriers, and platform administrators.



\## Applications



\- \*\*Movyra Client:\*\* Android application for customers.

\- \*\*Movyra Courier:\*\* Android application for delivery couriers.

\- \*\*Movyra Restaurant:\*\* Web application for restaurant owners.

\- \*\*Movyra Admin:\*\* Web application for platform administration.



\## Technology Stack



| Component | Technology |

|---|---|

| Android | Kotlin |

| Web | React |

| Backend | Java, Spring Boot |

| Database | MySQL |

| API | REST |

| Security | Spring Security, JWT |

| Version Control | Git, GitHub |



\## Architecture



Four independent frontend applications connected to one shared backend and database.
